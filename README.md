# StockCore - Sistema de Gestión de Stock

SaaS de gestión de inventario con frontend React y backend FastAPI.

## Estructura
- `/backend` - API FastAPI
- `/frontend` - Aplicación React

## Desarrollo
Ver `backend/README.md` para base de datos, configuración, migraciones y pruebas.
El frontend incluye productos, movimientos, stock por depósito y configuración.

Esta versión es para una empresa con múltiples depósitos. Los datos se guardan en PostgreSQL.
